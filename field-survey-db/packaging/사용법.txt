========================================
 오토다타 (AutoData) — 포터블 (설치 필요 없음)
 현장 조사 데이터 자동 DB화
========================================

[실행 방법]
1) 이 폴더를 통째로 원하는 곳에 복사합니다. (USB로 옮겨도 됩니다.)
2) 폴더 안의  FieldSurveyDB.exe  를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 → [추가 정보] → [실행] 을 누르세요.
3) 잠시 후 브라우저에 시작 화면이 열립니다. 까만 창은 그대로 두세요(닫으면 종료).
4) 다 쓰면 그 창에서 Ctrl+C 를 누르거나 창을 닫으면 종료됩니다.

[시작 화면 3개 메뉴]
- 🤖 AI 자동추출: 조사 데이터 파일들을 넣으면 AI(Vision)가 페이지를 읽고 서식을 판별해
  자동으로 표(DB)로 만듭니다. 박스·템플릿 없이 처음 보는 양식도 됩니다. (AI 설정 필요)
- 📐 템플릿 디자이너: 양식 위에 추출 박스를 확인·수정해 템플릿으로 저장하고
  일괄 처리(요약표+보고서)를 실행합니다. (AI 없이 완전 로컬로 동작)
- ⚙️ 환경설정: AI 제공자(Claude/ChatGPT/Gemini) 선택, API 키 입력(암호화 저장), 연결 테스트,
  종적 연속성 평가(SCE) 연계 켜기·끄기(선택 — 켠 경우에만 4번 결과 화면에 SCE 버튼이 생깁니다).

[AI 기능을 쓰려면 (선택)]
- 방법 1: 화면의 ⚙️ 환경설정에서 본인 API 키 입력(암호화 저장) + 연결 테스트.
- 방법 2: exe 옆  ai_config.txt  파일에 키를 넣어 두면 각자 설정 없이 바로 사용.
- AI를 안 켜면 템플릿 디자이너 등 기본 기능은 전부 이 컴퓨터 안에서만 동작합니다.

[다른 프로그램 설치가 필요한가요?]
- 파이썬 등 필요한 것은 전부 이 폴더 안에 들어 있습니다. 추가 설치 없음.
- 켜질 때 이 컴퓨터를 자동 점검해, 안 되는 것이 있으면 안내를 띄웁니다.
- 예외 1: '한글(HWP)' — hwpx 파일을 쓸 때만 필요합니다(아래 참고).
- 예외 2: 경량판의 스캔 문서 글자 인식 기능 — 처음 쓸 때 화면의 '받기'로 받습니다(아래 [글자 인식] 참고).

[시스템 점검 — 처음 설치한 PC에서 꼭 한 번]
- 첫 화면의 '🩺 시스템 점검'을 누르면 운영체제·CPU·메모리·디스크·GPU·한글·브라우저·
  포트·작업 폴더 쓰기·PDF/엑셀 엔진·글자 인식 엔진·AI 설정을 항목별로 확인합니다.
  · 정상: 바로 사용 가능  · 주의: 동작하지만 일부 기능 제약(예: 한글 없음 → hwpx 불가)
  · 불가: 해결해야 사용 가능(해결 방법이 같이 표시됨)  · 참고: 정보
- '📋 결과 복사'로 결과를 복사해 담당자에게 보낼 수 있습니다.
- 명령줄:  FieldSurveyDB.exe --check  → 전체 점검 후 exe 옆에 '시스템점검_결과.txt'를 남깁니다.
- 자세한 배포 절차는 함께 들어 있는 '배포_점검표.md'를 보세요.

[처리 속도 — CPU와 GPU 가속]
- 켤 때 까만 창의 [성능] 줄에 이 PC의 CPU·메모리·GPU와 글자 인식 처리 방식이 표시됩니다.
- CPU로 처리하면 스캔 문서 쪽당 약 10초 걸립니다.
- NVIDIA 그래픽카드(드라이버 580 이상)가 있는 PC는 GPU로 처리하면 약 7배 빨라집니다(쪽당 1~2초).
  · 경량판: ⚙️ 환경설정 → 5. 글자 인식 기능에서 'GPU 가속판 받기'(약 2GB)
  · 인터넷 없이 쓰는 PC: GPU판 배포본(FieldSurveyDB_GPU_포터블_….zip, 약 2.2GB)
  GPU가 없는 PC에서도 CPU로 정상 동작합니다.

[보안]
- 템플릿 디자이너의 추출·엑셀 생성은 이 컴퓨터에서만 처리됩니다(인터넷 전송 없음).
- AI 기능(자동추출·AI 이해·AI 분석)을 쓸 때만 해당 조사 데이터 내용이 선택한 AI(외부)로 전송됩니다.

[hwpx 파일을 올리려면]
- 이 컴퓨터에 '한글(HWP)'이 설치되어 있어야 hwpx 변환이 됩니다.
- ※ 변환이 오래 걸리거나 멈추면: 한글의 자동화 '보안 승인'이 필요할 수 있습니다.
  가장 확실한 방법 → 그 파일을 한글에서 [PDF로 저장] 한 뒤, PDF를 올리세요. (결과 동일)
- PDF 파일은 한글 없이도 바로 됩니다.

[템플릿 디자이너 주요 기능]
- 양식 하나를 올리면 표 칸마다 추출 박스 자동 생성 → 확인·수정 → 템플릿 저장
- 템플릿에는 양식 PDF가 함께 저장되어, 첫 화면에서 불러오면 조사 데이터가 그대로 보입니다.
- 일괄 처리: 조사 데이터 여러 개 → 엑셀(요약표 + 파일별 보고서), 이상치(오추출 의심) 경고 포함
- 한 파일에 조사 데이터가 여러 묶음 들어 있으면 자동 인식해 묶음마다 한 행씩 나옵니다.
- '대상지별 시트 이름'을 고르면 파일(묶음)마다 그 값(예: 하천명)으로 시트가 만들어집니다.
- 조사 데이터에 줄이 추가되거나 위치가 밀려도, 라벨 칸을 찾아 값을 읽어(유기적 추출) 정확합니다.
- 페이지 버튼의 ✕로 필요 없는 쪽을 빼고, '＋쪽 추가'로 다른 파일의 쪽을 붙일 수 있습니다.
- 상단 큰 글씨(제목)는 📑 제목 박스로 자동 인식 — 일괄 처리에서 "제목별 분류"를 고르면
  같은 양식끼리 제목 이름의 시트로 묶입니다.
- 항목 이름이 길이·높이·(m)처럼 수치를 뜻하면 '# 숫자' 유형으로 자동 지정됩니다.
  숫자 유형 칸은 단위·한글을 걷어내고(예: '약 25.5 m' → 25.5) 엑셀에 '수'로 기록되어
  합계·평균·정렬이 바로 됩니다. 번호·일자·좌표는 계산 대상이 아니라 일반으로 둡니다.
  값 일부만 숫자면(예: '좌안 12 우안 15') 정보가 잘리지 않도록 글자 그대로 둡니다.
- 머리글 한 줄 아래 데이터가 여러 줄 이어지는 표(담당자 명단, 측정값 목록 등)는
  ▤ '표(여러 행)' 박스 하나로 자동 인식됩니다(파란색). 일괄 처리하면 표의 데이터 줄마다
  엑셀 한 행이 되고, 열 이름은 표 머리글이 됩니다.
- 세로로 합쳐진 칸(여러 행에 걸친 칸)의 값은 걸친 행 전체에 해당하므로 행마다 같은 값이 들어갑니다.
  · 기관명·연락처처럼 한 줄인 값 → 그대로 모든 행에 반복
  · 담당자가 두 줄로 적힌 칸(공동 담당) → '김철수, 이영희' 처럼 쉼표로 한 값으로 합쳐 모든 행에 반복
  · 쉼표 없이 줄만 바뀐 값('건설과' / '하천팀') → '건설과 하천팀' 으로 이어 붙임
  · 줄바꿈으로 끊긴 이메일 → 한 주소로 이어 붙임
  직접 그린 박스도 항목 목록에서 '표(여러 행)'을 고르면 같은 방식으로 처리됩니다.
- 보고서 양식에서 {항목명#2} 처럼 순번을 붙이면 여러 조사 데이터를 한 시트에서 참조합니다.
- 보고서 양식(4번)의 "🤖 AI 초안 만들기": AI가 양식 초안을 만들어 줍니다 —
  다운로드해 엑셀에서 편집한 뒤 다시 올리면 그 양식대로 데이터가 채워집니다. (AI 설정 필요)

[만든 파일은 어디에?]
- 이 폴더 안 'data' 폴더에 작업 파일과 결과 엑셀이 쌓입니다.

[스캔(사진)·수기 문서 글자 인식(OCR)]
- 글자가 없는 스캔·사진 PDF는 자동으로 글자를 인식해 처리합니다. 준비 방식은 배포본마다 다릅니다.
  · 경량판(AutoData_Windows.zip — 웹 시작 페이지의 기본 내려받기): 글자 인식 기능이 들어 있지 않습니다.
    스캔 문서를 처음 올리면 '받기' 안내가 나옵니다(약 270MB, GPU 가속판 약 2GB).
    공개 저장소(PyPI·PyTorch·EasyOCR)에서 받아 이 컴퓨터에만 두고, 받은 파일은 고정된 SHA-256 값과
    맞을 때만 씁니다. 조사 데이터는 보내지 않습니다. 한 번 받으면 새 버전 도우미에서도 다시 받지 않습니다.
    ⚙️ 환경설정 → 5. 글자 인식 기능에서 미리 받거나 지울 수 있습니다.
  · 오프라인판(AutoData_Windows_offline.zip)·GPU판: 엔진과 한국어·영어 모델이 들어 있어 인터넷 없이 동작합니다.
- 스캔 문서도 표의 칸을 그림에서 찾아 추출 박스를 자동으로 만듭니다(왼쪽·위 칸 이름이 항목명이 됩니다).
  칸 기준으로 읽기 때문에 줄이 늘거나 위치가 밀린 조사표에서도 값이 맞습니다.
- 켠 뒤 처음 스캔 문서를 처리할 때 모델을 읽어 오느라 수십 초 걸릴 수 있습니다.
- 손글씨는 또박또박 쓴 글씨일수록 인식률이 높습니다. 인식이 애매한 값은 결과에서 확인하세요.

[설문지(칸 없는 서식) 자동 인식]
- 표(칸)가 없고 '1. 2. 3.' 문항 번호로 된 설문지는 템플릿 없이도 자동 인식됩니다.
  문항마다 열 하나, 선택된 답은 '번호:내용'(복수응답은 ;로 연결), 주관식은 글 그대로.
- 척도표(문항 행 × 1점~5점 열, 리커트)도 자동 인식합니다. 열 이름은 '문항01, 문항02…', 값은 점수.
- 스캔본에 손으로 동그라미·체크·사선을 친 표시도 잉크를 비교해 판정합니다.
  흐리거나 애매한 표시는 엑셀에서 주황 칸 + 메모로 '확인 필요'를 알려 드립니다.
