## 설치

1. 아래 **AutoData_Windows.zip** 을 내려받습니다.
2. 원하는 폴더에 압축을 풉니다. 설치나 관리자 권한은 필요 없습니다.
3. 폴더 안의 `FieldSurveyDB.exe` 를 실행합니다. 까만 창이 떠 있는 동안 도우미가 켜져 있습니다.
4. 시작 페이지 https://autodata.singlena.workers.dev 에서 **다시 찾기** → 브라우저가 로컬 네트워크 접근을 물으면 허용합니다.

조사 파일 · AI 키 · 결과 엑셀은 모두 그 컴퓨터에만 저장됩니다.
이전 버전 폴더의 `data` 폴더(양식·결과)를 새 폴더로 옮기면 그대로 이어서 쓸 수 있습니다.

- 대상: Windows 10·11 (64비트)
- 한글(HWP) 파일 변환은 한글 프로그램이 설치된 PC에서 동작합니다.
