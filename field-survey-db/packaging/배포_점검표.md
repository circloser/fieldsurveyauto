# 오토다타 (AutoData) 사내 배포 점검표

담당자가 배포 전·후에 확인하는 절차입니다. 프로그램 자체가 켜질 때 자동 점검을 하고,
브라우저의 **🩺 시스템 점검** 메뉴(또는 `FieldSurveyDB.exe --check`)로 항목별 결과를 볼 수 있습니다.

## 1. 배포본 고르기

| 배포본 | zip 이름 | 용량 | 언제 |
|---|---|---|---|
| **기본판** (CPU 처리, OCR 포함) | `FieldSurveyDB_포터블_날짜_시간.zip` | 약 430MB | 대부분의 업무용 PC. 스캔 문서는 쪽당 약 10초 |
| **GPU판** (GPU 가속, OCR 포함) | `FieldSurveyDB_GPU_포터블_날짜_시간.zip` | 약 3.5GB | NVIDIA GPU가 있는 PC. 스캔 문서 쪽당 1~2초(약 7배 빠름) |
| 경량판 (OCR 없음) | `FieldSurveyDB_경량_포터블_날짜_시간.zip` | 약 100MB | 글자가 있는 PDF·hwpx 만 다루는 PC |

- GPU판 조건: NVIDIA 그래픽카드(GeForce/RTX/Quadro) + **NVIDIA 드라이버 580 이상**. 그래픽카드가 없거나
  AMD/Intel 내장 그래픽뿐이면 GPU판을 넣어도 CPU로 동작합니다(기본판과 같음).
- 두 배포본은 기능이 같습니다. 처리 속도(스캔 문서 글자 인식)만 다릅니다.

## 2. PC 최소 요건

| 항목 | 최소 | 권장 |
|---|---|---|
| 운영체제 | Windows 10 (64비트) 1809 이상 | Windows 11 |
| CPU | 4스레드 | 8스레드 이상 |
| 메모리 | 4GB | 8GB 이상(스캔 문서 여러 장 처리) |
| 디스크 여유 | 2GB (GPU판 8GB) | 10GB 이상 |
| 그래픽 | 없어도 됨 | NVIDIA GPU(GPU판) |
| 추가 프로그램 | **없음** (파이썬 등 전부 동봉) | 한글(HWP) — hwpx 파일을 쓸 때만 |
| 인터넷 | **불필요** (모든 처리는 PC 안에서) | AI 기능을 쓸 때만 필요 |
| 권한 | 일반 사용자 (관리자 권한 불필요) | |

## 3. 설치(복사) 절차

1. zip을 **쓰기 가능한 폴더**에 풉니다 — 예: `C:\AutoData\` 또는 `문서\AutoData\`.
   - `C:\Program Files\` 나 네트워크 드라이브에는 넣지 마세요(작업 폴더 `data\`를 못 만듭니다).
2. 폴더 안 `FieldSurveyDB.exe` 를 더블클릭합니다.
   - "Windows의 PC 보호" 창(SmartScreen) → **[추가 정보] → [실행]**.
   - 백신이 검사하느라 첫 실행이 느릴 수 있습니다(1~2분). 두 번째부터는 빠릅니다.
3. 까만 창에 `[성능]`·`[점검]` 줄이 뜨고 브라우저가 열리면 정상입니다.
4. 브라우저 첫 화면의 **🩺 시스템 점검**을 눌러 항목이 모두 정상/주의인지 확인합니다.
   - **불가** 항목이 있으면 그 줄의 해결 방법대로 조치한 뒤 다시 점검합니다.
   - **주의: 한글(HWP) 없음** → hwpx 파일만 못 씁니다(PDF는 됩니다). 필요하면 한글 설치.

## 4. 점검 항목과 조치

| 항목 | 정상 기준 | 문제 시 조치 |
|---|---|---|
| 운영체제 | Windows 64비트 | 32비트 PC는 지원하지 않음 |
| CPU / 메모리 | 4스레드 / 8GB↑ | 미달이면 동작은 하나 스캔 처리가 느림 |
| 디스크 여유 공간 | 2GB↑ | `data\` 폴더의 오래된 결과 파일 정리 |
| GPU 가속 | 정보 항목 | NVIDIA GPU가 있는데 "CPU 처리판"이면 GPU판으로 교체 |
| 한글(HWP) | 설치됨 | hwpx 변환에만 필요. 없으면 한글에서 [PDF로 저장] 후 PDF 사용 |
| 웹 브라우저 | 기본 브라우저 있음 | 없으면 주소(`http://127.0.0.1:8765`)를 직접 입력 |
| 네트워크 포트 | 8765 사용 가능 | 사용 중이면 자동으로 다음 포트 사용(정상) |
| 작업 폴더 쓰기 | `data\` 쓰기 가능 | 폴더를 문서·바탕화면 등으로 이동 |
| PDF 엔진 / 엑셀 출력 | 사용 가능 | 불가면 zip이 덜 풀린 것 — 다시 풀기 |
| 글자 인식(OCR) | 엔진 로드 성공 | 경량판이면 스캔 문서 불가 — 기본판/GPU판 사용 |
| AI 기능(선택) | 정보 항목 | AI 자동 추출을 쓸 PC만 환경설정에서 키 입력 |

## 5. 명령줄 점검(IT 담당자용)

```
FieldSurveyDB.exe --check
```
전체 점검(글자 인식 엔진 로드 포함, 최대 30초)을 돌려 화면에 출력하고
exe 옆에 `시스템점검_결과.txt` 를 남깁니다. 여러 PC의 결과를 모아 확인할 때 쓰세요.

## 6. 보안·네트워크 안내(정보보안 담당 참고)

- 프로그램은 `127.0.0.1`(이 PC 안)에서만 통신합니다. 외부·사내망으로 포트를 열지 않습니다.
- 조사 데이터는 PC 안에서만 처리·저장됩니다. **AI 기능을 켠 경우에만** 선택한 AI 제공자로 문서 내용이 전송됩니다.
- API 키는 Windows 계정 암호화(DPAPI)로 저장됩니다.
- 백신 예외 등록이 필요하면 설치 폴더 전체(특히 `FieldSurveyDB.exe`, `_internal\`)를 등록하세요.

## 7. 업데이트

새 zip을 같은 방식으로 풀고 **`data\` 폴더만** 옛 폴더에서 새 폴더로 복사하면
템플릿·설정·결과가 그대로 유지됩니다(`ai_settings.enc`, `ai_config.txt` 도 함께).
