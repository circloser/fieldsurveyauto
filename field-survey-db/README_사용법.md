# 현장 조사표 DB화 — 사용 설명서

> 국립생태원 습지복원팀 내부용 · 완전 무료 · 이 컴퓨터 안에서만 실행(자료 외부 유출 없음)

## 이게 뭔가요?
현장조사표(hwpx·hwp·pdf)를 여러 개 올리면, 안의 내용을 자동으로 읽어서
**엑셀 DB 파일**로 정리해 주는 프로그램입니다. 수기 입력을 대신합니다.

## 처음 한 번만 (설치)
1. 이 폴더의 **`install.bat`** 을 더블클릭합니다.
   - 파이썬과 필요한 라이브러리를 자동으로 설치합니다. (인터넷 필요, 몇 분 소요)
   - "Windows의 PC 보호" 창이 뜨면 → **추가 정보 → 실행**을 누르세요.
2. "설치 완료" 메시지가 나오면 끝입니다.

> 파이썬이 없다는 오류가 나오면: https://www.python.org/downloads/ 에서 **Python 3.11** 을 받아
> 설치할 때 **"Add Python to PATH"** 를 꼭 체크한 뒤, 다시 `install.bat` 을 실행하세요.

## 매번 실행할 때
- **`start.bat`** 을 더블클릭합니다.
- 잠시 후 인터넷 브라우저(크롬/엣지)에 화면이 자동으로 열립니다.
- 까만 실행 창은 그대로 두세요(닫으면 프로그램이 꺼집니다).
- 다 쓰면 그 창에서 **Ctrl + C** 를 누르거나 창을 닫으면 종료됩니다.

## 현재 단계
- **Phase 0** — 프로그램이 정상적으로 켜지는지 확인하는 단계입니다.
  화면에 "정상 작동 중" 초록불이 보이면 성공입니다.
- 다음 단계부터 파일 업로드·자동 추출·엑셀 다운로드 기능이 추가됩니다.

## 스캔(이미지) PDF도 읽고 싶다면 (선택)
- 타이핑된 hwpx·PDF는 그냥 읽힙니다. **스캔본(사진/이미지 PDF)** 만 OCR이 필요합니다.
- OCR 기능은 용량이 커서 기본 설치에 빠져 있습니다. 필요하면 한 번만 설치하세요:
  1. `install.bat` 이 있는 폴더에서
  2. `.venv\Scripts\python.exe -m pip install -r requirements-ocr.txt` 실행
- 설치 후에는 스캔 PDF를 올리면 자동으로 글자를 인식합니다(정확도 100%는 아니므로 검수 권장).

## 🤖 AI 자동 양식 이해 (선택)
- 처음 보는 양식이라도 **Claude AI가 표를 읽고 "이건 하천명, 이건 보 길이"처럼 추출 항목을
  자동으로 찾아 이름까지** 붙여 줍니다. 박스를 일일이 정리하는 수고를 크게 줄여 줍니다.
- 화면 2번(박스 확인·정리)의 **🤖 AI 자동 이해** 버튼으로 실행합니다.
- 켜는 방법(한 번만):
  1. `.venv\Scripts\python.exe -m pip install -r requirements-ai.txt` 실행
  2. Claude API 키를 환경변수 `ANTHROPIC_API_KEY` 로 설정한 뒤 `start.bat` 을 다시 실행
  - (설정 전에는 버튼에 "설정 필요"로 표시되며 동작하지 않습니다.)
- ⚠️ **보안 안내:** 이 버튼을 누를 때만 **양식 1건의 '칸 글자'가 인터넷으로 Claude(외부)** 에
  전송됩니다. **대량 실데이터 추출은 계속 이 컴퓨터 안에서만** 처리됩니다(외부 전송 없음).
  AI가 붙인 이름은 화면에서 확인·수정할 수 있습니다.

## 자주 묻는 질문
- **Q. 인터넷에 자료가 올라가나요?** 기본 기능(추출·엑셀 만들기·OCR)은 전부 이 컴퓨터 안에서만
  처리됩니다. 예외는 **🤖 AI 자동 이해** 버튼 하나뿐이며, 이때만 양식 1건의 칸 글자가 Claude로
  전송됩니다(선택 기능 · 안 켜면 전송 없음).
- **Q. 돈이 드나요?** 전혀요. 모두 무료입니다.
- **Q. 창을 두 번 켰어요.** 괜찮습니다. 자동으로 다른 포트를 찾아 실행됩니다.
