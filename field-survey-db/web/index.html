작업 화면 열기

도우미를 처음 쓰거나 찾지 못했다면

  1. 받기 최신 도우미 내려받기 — Windows 10·11용 압축 파일 (바뀐 점)
  2. 압축 풀기 원하는 폴더에 풀어 두세요. 설치나 관리자 권한은 필요 없습니다.
  3. 실행 폴더 안의 FieldSurveyDB.exe를 실행하세요. 까만 창이 떠 있는 동안 도우미가 켜져 있습니다.
  4. 허용 이 페이지에서 다시 찾기를 누르세요. 브라우저가 이 사이트의 로컬 네트워크 접근을 물으면 허용해 주세요. 이미 거절했다면 주소창 왼쪽의 사이트 정보 → 사이트 설정에서 바꿀 수 있습니다.
