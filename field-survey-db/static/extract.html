1. 추출에 쓰는 템플릿

저장된 템플릿 전체로 양식을 자동 분류합니다. 제목이 없는 스캔 문서를 특정 양식으로 읽게 하려면 기준 템플릿을 고르세요.

    템플릿을 새로 만들거나 고치려면 템플릿 디자이너로.

    2. 일괄 처리

    파일들을 선택하고 버튼만 누르세요 — 양식을 알아보고 제목별 시트로 정리합니다. 설문지(문항 번호 목록·척도표)는 템플릿 없이 자동 인식하고, 이상한 값은 표시해 드립니다.

    3. 보고서 출력 양식 선택

    2번 실행 후 — 엑셀 양식(.xlsx)을 올리고 ‘보고서로 정리’를 누르면 결과가 양식에 채워집니다. 수식은 보존됩니다.
