# AI 자동추출 사용법 (직원용)

각종 서식·양식(hwpx·PDF)을 넣으면 **AI가 페이지별로 알아서 읽어 엑셀 표로** 만들어 줍니다.
양식 종류를 몰라도 됩니다. 정의된 서식(인공구조물·대표지점·어도·어류·횡적연속성)은 물론,
**처음 보는 다른 조사표도 "범용 모드"로 자동 표화**합니다.

## 1. 실행

1. 배포받은 폴더(`FieldSurveyDB`)를 통째로 원하는 위치에 복사.
2. **`FieldSurveyDB.exe` 더블클릭** → 잠시 후 브라우저가 자동으로 열립니다.
   - 검은 콘솔 창은 서버 창입니다. **끄지 마세요**(끄면 프로그램 종료). 다 쓰면 그 창에서 Ctrl+C.

> hwpx 파일을 쓰려면 이 PC에 **한글(HWP)** 이 설치돼 있어야 합니다. **PDF는 한글 없이도** 됩니다.

## 2. AI 키 등록 — 화면의 ⚙️ 환경설정 메뉴에서 (txt 편집 불필요)

1. 상단 **⚙️ 환경설정(AI 키)** 메뉴 클릭.
2. **제공자 선택**: Claude(Anthropic) / ChatGPT(OpenAI) / Gemini(Google) 중 하나.
3. 그 제공자의 **본인 API 키** 입력 → **저장**. (각자 본인 키·본인 사용량으로 동작)
   - 키 발급: Claude=console.anthropic.com · OpenAI=platform.openai.com · Gemini=aistudio.google.com
4. **[🔌 연결 테스트]** 로 키가 맞는지 즉시 확인.

> 🔒 입력한 키는 이 PC에 **암호화(Windows DPAPI)** 되어 저장됩니다. 텍스트 파일에 평문으로 두지 않습니다.
> 다른 사용자·다른 PC로 파일을 복사해도 열 수 없습니다. (같은 사용자 프로그램은 사용 가능 — 로컬 앱의 한계)

## 3. AI 자동추출 화면

상단 **🤖 AI 자동 추출** 메뉴로 이동.

1. **파일 선택**(여러 개 가능, hwpx/PDF) → **[AI로 추출]** 클릭.
2. 페이지마다 서식이 자동 판별되고 값이 채워집니다. (사진 페이지 등은 자동 건너뜀)
3. **[📊 데이터 분석]** 으로 전체 요약·추세를, **[엑셀 다운로드]** 로 결과 저장(서식별 시트).

## 4. 검수 (중요)

AI가 100% 완벽하진 않으니 **눈으로 한 번 확인**하세요. 화면 색 표시:
- **노란 칸** = 빈값(원본이 빈칸인지 확인)
- **빨간 칸** = 숫자 자리 형식 이상(오인식 의심)
- **주황 칸 / ⚠️ 이상치** = 다른 조사표와 비교해 튀는 값(오추출 의심) → 꼭 확인
- **"🔎 범용 자동추출"** = 정의된 서식이 아니라 AI가 자유 추출 → 특히 꼼꼼히

값을 **직접 고치면** 자동 저장되고 엑셀에도 반영됩니다.

## 5. 개인정보 주의
- 추출 시 페이지 이미지가 선택한 AI 제공자로 전송됩니다(**프로그램에 저장은 안 됨**).
- **발표·외부 공유 자료**에는 조사자 이름·좌표 등 개인정보를 **가리고(마스킹)** 쓰세요.

## 6. 잘 안 될 때
- "AI 사용 불가" → ⚙️ 환경설정에서 제공자와 본인 키를 넣고 저장했는지 확인 → 연결 테스트.
- "이미지 요청 거부(403)" → 짧은 시간 많이 몰리면 나올 수 있음. **잠시 후 다시** 시도.
- hwpx 변환 오류 → 한글(HWP) 설치 필요. 급하면 PDF로 저장해 올리세요.
