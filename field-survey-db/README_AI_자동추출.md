# AI 자동추출 사용법 (직원용)

현장 조사표(hwpx·PDF)를 넣으면 **AI가 페이지별로 알아서 읽어 엑셀 표로** 만들어 줍니다.
양식 종류를 몰라도 됩니다. 정의된 서식(인공구조물·대표지점·어도·어류·횡적연속성)은 물론,
**처음 보는 다른 조사표도 "범용 모드"로 자동 표화**합니다.

## 1. 실행

1. 배포받은 폴더(`FieldSurveyDB`)를 통째로 원하는 위치에 복사.
2. **AI 기능을 쓰려면 본인 API 키 등록** (한 번만):
   - 폴더 안 **`ai_config.txt`** 를 메모장으로 열고,
   - `ANTHROPIC_API_KEY=` 뒤에 **본인의 Claude(Anthropic) API 키**를 붙여넣고 저장.
   - 키 발급: https://console.anthropic.com → API Keys. (각자 본인 키·본인 사용량으로 동작)
   - AI 없이 추출 결과 확인만 할 거면 이 단계는 건너뛰어도 됩니다(그 경우 AI 기능만 비활성).
3. **`FieldSurveyDB.exe` 더블클릭** → 잠시 후 브라우저가 자동으로 열립니다.
   - 검은 콘솔 창은 서버 창입니다. **끄지 마세요**(끄면 프로그램 종료). 다 쓰면 그 창에서 Ctrl+C.

> hwpx 파일을 쓰려면 이 PC에 **한글(HWP)** 이 설치돼 있어야 합니다. **PDF는 한글 없이도** 됩니다.

## 2. AI 자동추출 화면

브라우저 주소창에 `/ai` 를 붙여 이동하거나(예: `http://127.0.0.1:8765/ai`), 화면 링크로 이동.

1. **파일 선택**(여러 개 가능, hwpx/PDF) → **[AI로 추출]** 클릭.
2. 페이지마다 서식이 자동 판별되고 값이 채워집니다. (사진 페이지 등은 자동 건너뜀)
3. **[엑셀 다운로드]** 로 결과 저장. 서식별로 시트가 나뉩니다.

## 3. 검수 (중요)

AI가 100% 완벽하진 않으니 **눈으로 한 번 확인**하세요. 화면에서:
- **노란 칸** = 값이 비어 있음(원본이 빈칸인지 확인)
- **빨간 칸** = 숫자 자리에 이상한 값(오인식 의심)
- **"🔎 범용 자동추출"** 표시 = 정의된 서식이 아니라 AI가 자유롭게 뽑은 것 → 특히 꼼꼼히 검수

값을 **직접 고치면** 자동 저장되고 엑셀에도 반영됩니다.

## 4. 개인정보 주의

- 추출 시 이미지가 회사 프록시 서버를 거쳐 AI로 전송됩니다(**저장은 안 됨**).
- **발표·외부 공유 자료**에는 조사자 이름·좌표 등 개인정보를 **가리고(마스킹)** 쓰세요.

## 5. 잘 안 될 때
- "AI 사용 불가" 표시 → `ai_config.txt` 에 본인 `ANTHROPIC_API_KEY` 를 넣었는지 확인(exe 옆에 위치).
- "이미지 요청 거부(403)" → 잠깐 많이 몰렸을 때 나올 수 있습니다. **잠시 후 다시** 시도.
- hwpx 변환 오류 → 한글(HWP) 설치 필요. 급하면 PDF로 저장해 올리세요.
